# Mihai Munteanu — Software, connected.

Компактный сайт-портфолио с двумя отдельными информационными страницами. Без личных фотографий, длинного резюме, выдуманных клиентов и неработающей формы.

## Запуск

Node **24 LTS** (минимум 22.22), npm.

```sh
npm ci
npm run dev
```

```sh
npm run check
npm test
npm run build
npm run preview
```

Статическая production-сборка находится в `dist/`. Сервер, база данных, API-ключи и переменные окружения не нужны. Рабочая версия хранится в `main`; публикация следует существующей интеграции хостинга с GitHub.

## Редактирование

- `src/data/profile.ts` — имя, специализация, адрес, весь основной текст, три concept-проекта и контакты.
- `src/page.mjs` — секции главной, общие `renderContactDetails` и `renderFooter`.
- `src/styles/base.css` — палитра и базовые размеры; `sections.css`, `responsive.css` и `scene.css` — секции, адаптивность и 3D fallback; `contact.css` — иконки, контактные строки и ссылки footer.
- `src/data/legal.ts` — английские тексты Privacy Policy / Terms of Service и дата редакции; контакты подставляются из `profile.ts`.
- `src/layouts/LegalLayout.astro`, `src/styles/legal.css` — единое оформление документов.
- `src/scripts/core.mjs` — `CYCLE_SECONDS = 12` и `SHOWCASE_SECONDS = 6`.
- `src/scripts/geometry.mjs` — координаты трёх модулей и маршрутов, общие для 3D и запасного визуала.
- `src/scripts/hero-scene.mjs` — процедурная сцена Three.js.
- `src/pages/index.astro` — метаданные и документ главной.

Стек: **Astro, TypeScript, CSS, Three.js, GSAP**. Основной HTML доступен без JavaScript. Three.js загружается отдельно; при отказе WebGL остаётся совпадающая по композиции CSS 3D-модель. Никаких внешних моделей, портретов и шрифтовых CDN. Информационные страницы не загружают JavaScript, Three.js или анимационную сцену.

## Контакт и домен

`contactEmail: 'mihai.muntenau@inbox.eu'` — адрес предоставлен заказчиком; написание **muntenau** сохранено буквально. Контактная строка с конвертом — настоящий `mailto:`. Он открывает почтовое приложение посетителя, а не отправляет сообщение с сайта. Рядом находится адрес с иконкой геометки. Кнопки копирования и GitHub из интерфейса удалены. При `contactEmail: null` ссылка не показывается.

`siteUrl: null` — окончательный домен не закреплён в конфигурации. При его добавлении появятся canonical и абсолютные Open Graph URL. Не подставляйте временный закрытый preview вместо постоянного домена. `public/social.svg` содержит визуал для превью; для площадок, не поддерживающих SVG, экспортируйте его в PNG и замените путь в `index.astro`.

В footer всех страниц находятся `/privacy/` и `/terms-of-service/`. Это маршруты Astro, не ссылки на чужие примеры. Юридические допущения и первичные источники — в `docs/CONTACT-LEGAL.md`. Тексты требуют сверки владельцем с фактическими реквизитами и практиками обработки данных; отсутствующие сведения о бизнесе не выдумываются.

## Движение

В шапке главной есть `Full / Reduced / Off`. Начальное рабочее состояние — Full. Явно выбранный режим сохраняется и имеет приоритет. При отключённых системных эффектах можно выбрать **Full** непосредственно на сайте. Reduced не прячет содержимое, Off не отключает ручное управление.

Одна шкала времени синхронизирует Receive → Process → Sync с сигналами. Рендер останавливается за пределами экрана и в скрытой вкладке. После ручного выбора проекта карусель ожидает Play; обычное наведение мыши не останавливает прогресс. Управление каруселью и 3D не изменялось при добавлении контактов и документов.

## Проверки

```sh
npx playwright install chromium firefox
npm run build
npm run test:browser
```

Небольшие Node-тесты проверяют математику, HTML, контакты и наличие маршрутов. Основной Playwright smoke в Chromium проверяет пиксели 3D, режимы движения, адаптивность, карусель, меню и fallback. Отдельные сценарии контактов и информационных страниц выполняются также в Firefox, в том числе без JavaScript. Это не утверждение о прогоне всей 3D-сцены в Firefox.

Проверки запускают именно собранный сайт. Mailto проверяется без отправки письма. Скриншоты сохраняются в `qa/`, а конкретный проверенный commit и результаты — в CI-артефакте `portfolio-verification` и PR. Физические устройства не подменяются эмуляцией размеров окна.

## Содержательные границы

Имя, страна, адрес, email и исходная область деятельности получены от заказчика. Узкое позиционирование и тексты услуг — предложенная профессиональная концепция, требующая подтверждения владельцем. Три проекта явно обозначены как concept studies, а не выполненные клиентские заказы. Стаж, работодатели, отзывы, измеренные результаты и юридические реквизиты не выдумывались.
