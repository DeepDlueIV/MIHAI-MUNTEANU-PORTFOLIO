# Mihai Munteanu — Portfolio

Одностраничный сайт персонального software consultant в Париже.

## Бриф

- Без фотографий человека; визуальная идентичность — монограмма MM и оригинальная 3D-композиция.
- Короткие английские тексты, пять компактных разделов; не длинное резюме.
- Узкая специализация: backend architecture и business-system integrations.
- Проекты помечены как концептуальные, без вымышленных клиентов и результатов.
- Анимация с режимами Full / Reduced / Off и сохранением явного выбора пользователя.
- Контакты не содержат выдуманного email или имитации отправки.

Разработка ведётся в отдельной рабочей ветке. Сайт и настройки внешнего хостинга автоматически не публикуются.
