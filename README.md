# Mihai Munteanu — Software, connected.

Компактный одностраничный сайт-портфолио. Без личных фотографий, длинного резюме, выдуманных клиентов и неработающей формы.

## Запуск

Node **24 LTS** (минимум 22.22), npm.

```sh
npm ci
npm run dev
```

```sh
npm run check
npm test
npm run build
npm run preview
```

Статическая production-сборка находится в `dist/`. Сервер, база данных, API-ключи и переменные окружения не нужны. Внешний хостинг этой задачей не настраивается.

## Редактирование

- `src/data/profile.ts` — имя, специализация, адрес, весь основной текст, три concept-проекта и контакты.
- `src/styles/base.css` — палитра и базовые размеры; `sections.css`, `responsive.css` и `scene.css` — секции, адаптивность и 3D fallback.
- `src/scripts/core.mjs` — `CYCLE_SECONDS = 12` и `SHOWCASE_SECONDS = 6`.
- `src/scripts/geometry.mjs` — координаты трёх модулей и маршрутов, общие для 3D и запасного визуала.
- `src/scripts/hero-scene.mjs` — процедурная сцена Three.js.
- `src/pages/index.astro` — метаданные и документ. `src/page.mjs` — семантическое содержимое секций.

Стек: **Astro, TypeScript, CSS, Three.js, GSAP**. Основной HTML доступен без JavaScript. Three.js загружается отдельно; при отказе WebGL остаётся совпадающая по композиции CSS 3D-модель. Никаких внешних моделей, портретов и шрифтовых CDN.

## Контакт и домен

`contactEmail: null` — реальная почта пока не предоставлена. Чтобы включить настоящую кнопку `mailto:` и копирование почты, укажите адрес в `src/data/profile.ts`. Сейчас в контактах доступно копирование предоставленного почтового адреса. Отправка писем не имитируется.

`siteUrl: null` — окончательный домен неизвестен. При его добавлении появятся canonical и абсолютные Open Graph URL. Не подставляйте временный закрытый preview вместо постоянного домена. `public/social.svg` содержит визуал для превью; для площадок, не поддерживающих SVG, экспортируйте его в PNG и замените путь в `index.astro`.

GitHub в footer ведёт на главную GitHub, не на вымышленный профиль владельца.

## Движение

В шапке есть `Full / Reduced / Off`. При первом посещении учитывается системный `prefers-reduced-motion`; явно выбранный режим сохраняется и имеет приоритет. Если в Windows выключены системные эффекты, выберите **Full** на сайте: менять настройки ПК не требуется. Reduced не прячет содержимое, Off не отключает ручное управление.

Одна шкала времени синхронизирует Receive → Process → Sync с сигналами. Рендер останавливается за пределами экрана и в скрытой вкладке. Карусель ставится на паузу при наведении, фокусе и ручном выборе.

## Проверки

Шесть небольших Node-тестов проверяют приоритет движения, границы фаз/маршрутов, HTML и реальные контактные состояния. Для проверок в браузере:

```sh
npx playwright install chromium
npm run build
npm run test:browser
```

Playwright запускает собранный сайт, сравнивает пиксели самой 3D-сцены и проверяет режимы движения, адаптивность, карусель, меню, отсутствие JS/WebGL/storage и контакты. Скриншоты сохраняются в `qa/`, сведения о конкретном прогоне — в `REVIEW.md` и артефакте проверки GitHub.

Локальная среда подготовки не имеет доступа к npm и блокирует браузерную навигацию; поэтому полная проверка Astro/Three.js выполняется в изолированном GitHub Actions runner этого репозитория, а не заменяется заявлением о проверке недоступного браузера.

## Содержательные границы

Имя, страна, адрес и исходная область деятельности получены от заказчика. Узкое позиционирование и тексты услуг — предложенная профессиональная концепция, требующая подтверждения владельцем. Три проекта явно обозначены как concept studies, а не выполненные клиентские заказы. Стаж, работодатели, отзывы, измеренные результаты и юридические реквизиты не выдумывались.
