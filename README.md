# Mihai Munteanu — Software, connected.

Компактный сайт специалиста по backend и интеграциям с двумя информационными страницами. Без личных фотографий, длинного резюме, выдуманных клиентов и неработающей формы.

## Запуск

Node **24 LTS** (минимум 22.22), npm.

```sh
npm ci
npm run dev
```

```sh
npm run check
npm test
npm run build
npm run preview
```

Статическая production-сборка находится в `dist/`. Сервер, база данных, API-ключи и переменные окружения не нужны. Рабочая версия хранится в `main`; публикация следует существующей интеграции хостинга с GitHub.

## Редактирование

- `src/data/profile.ts` — имя, специализация, адрес, основной текст, три схемы интеграции и контакты. Массив `projects` сохранён ради совместимости, но описывает услуги и технические подходы, не историю клиентских заказов.
- `src/page.mjs` — секции главной, общие `renderContactDetails` и `renderFooter`.
- `src/styles/base.css` — палитра и базовые размеры; `sections.css`, `responsive.css`, `scene.css` — секции, адаптивность и 3D fallback; `contact.css` — контактные строки и footer.
- `src/data/legal.ts` — тексты Privacy Policy / Terms of Service и дата редакции; контакты берутся из `profile.ts`.
- `src/layouts/LegalLayout.astro`, `src/styles/legal.css` — оформление документов.
- `src/scripts/core.mjs` — `CYCLE_SECONDS = 12` и `SHOWCASE_SECONDS = 6`.
- `src/scripts/geometry.mjs` — координаты модулей и маршрутов, общие для 3D и запасного визуала.
- `src/scripts/hero-scene.mjs` — процедурная сцена Three.js.
- `src/pages/index.astro` — метаданные и начальное применение настройки движения.

Стек: **Astro, TypeScript, CSS, Three.js, GSAP**. Основной HTML доступен без JavaScript. Three.js загружается отдельно; при отказе WebGL остаётся CSS 3D-модель. Информационные страницы не загружают JavaScript или Three.js.

## Контакты и страницы

Email **`mihai.muntenau@inbox.eu`** предоставлен заказчиком. Написание **muntenau** не исправлять. Контактная строка с конвертом — настоящий `mailto:`: открывает почтовое приложение, а не отправляет сообщение с сайта. Адрес сопровождается геометкой. Кнопки копирования и GitHub удалены. При `contactEmail: null` ссылка не показывается.

Маршруты: `/`, `/privacy/`, `/terms-of-service/`. В footer находятся обе информационные страницы. Пункт Solutions ведёт к `#work`: существующий hash сохранён для совместимости ссылок.

`siteUrl: null` — окончательный домен не подтверждён в конфигурации. После его указания появятся canonical и абсолютные Open Graph URL. Не подставляйте закрытый preview. `public/social.svg` содержит социальное превью; для площадок без поддержки SVG потребуется PNG и обновление пути в `index.astro`.

## Движение

В шапке есть `Full / Reduced / Off`. По умолчанию — Full, в том числе до загрузки основного модуля. Явно выбранный режим сохраняется и имеет приоритет. Reduced не скрывает содержимое, Off сохраняет ручное управление.

Одна шкала времени синхронизирует Receive → Process → Sync с сигналами. Тяжёлый рендер останавливается вне экрана и в скрытой вкладке. После ручного выбора панели карусель ожидает Play; наведение мыши не останавливает прогресс.

## Проверки

```sh
npx playwright install chromium firefox
npm run build
npm run test:browser
```

Node-тесты проверяют математику, контакты и контракт публичного текста. Основной интерактивный smoke выполняется в Chromium. Тексты, внутренние ссылки, метаданные, контакты и информационные страницы отдельно проверяются в Chromium и Firefox, в том числе без JavaScript. Проверки запускают собранный сайт; mailto не отправляет тестовое письмо. Скриншоты, полный текст всех страниц и проверенный SHA находятся в CI-артефакте `portfolio-verification`.

## Содержательные границы и публикация

Имя, страна, адрес, email и исходная область деятельности получены от заказчика. Специализация и описание услуг являются предложенным позиционированием, которое владелец должен подтвердить. Integration patterns — технические схемы, не выполненные клиентские заказы. Стаж, отзывы, работодатели, измеренные результаты и регистрационные данные не выдуманы.

Актуальный вывод и оставшиеся условия запуска: [owner-oriented self-review](docs/PUBLICATION-REVIEW.md). Редактура публичного текста завершена; фактические реквизиты оператора, обработка данных, допустимость коммерческого хостинга и публичный домен не подтверждаются одним прохождением CI. История подготовки юридических страниц: `docs/CONTACT-LEGAL.md`; при расхождении руководствоваться последним review и фактическими данными владельца.
