# Portfolio — рабочий план

Исполнение: Superpowers executing-plans, inline. Заказчик передал законченный бриф и делегировал обратимые решения; промежуточные согласования не нужны.

## Цель и ограничения

Пять компактных секций, 300–400 слов основного английского текста, без фотографий и вымышленных достижений. Backend architecture / business-system integrations. Монограмма MM и одна процедурная 3D-система. Одна карусель концепт-проектов. Full / Reduced / Off с явным override системного reduce.

## Архитектура

Astro + TypeScript + CSS + Three.js + GSAP. Статический HTML и независимые улучшения: навигация, showcase, 3D. Общие координаты и фазы у GPU-сцены и компактного CSS fallback. Никаких backend, CMS, базы данных и внешних API.

## Последовательность

1. Исходные данные и сжатый контент, законченный layout без портрета.
2. Единое управление движением, Three.js и matching fallback; реальные якоря, меню, карусель и контакты.
3. Минимальные тесты фаз/приоритетов/HTML, затем production-сборка и Chromium smoke.
4. Просмотр desktop/mobile и нескольких кадров самой сцены; исправление конкретных дефектов; owner-oriented self-review.
5. Исходники и lock-файл в этой ветке, README и REVIEW, готовая сборка. Без публикации на внешнем хостинге.

## Проверка среды

Локальная установка npm недоступна, браузерная навигация заблокирована политикой среды. Локально проверены ядро и генерация HTML. Для проверки исходно согласованного стека используется один ограниченный GitHub Actions runner этого же репозитория. Локальные ограничения не снимаются. Результаты runner до фактического завершения не объявляются успешными.
