## Что нельзя подтвердить из исходников

**Юридический издатель и обязательные сведения.** Даны имя, адрес, email и обозначение Director, но не названы юридическое лицо или статус самостоятельного предпринимателя. Владелец должен подтвердить, кто публикует сайт и выступает оператором данных. Требуется сверить применимые французские mentions légales: юридический статус, необходимые регистрационные сведения, контактный телефон и сведения о хостере/издателе. Отсутствующие значения не заменены вымыслом. Для продаж потребителям дополнительно проверяются применимые потребительские обязанности. См. [разъяснение Министерства экономики Франции](https://www.economie.gouv.fr/entreprises/developper-son-entreprise/innover-et-numeriser-son-entreprise/mentions-sur-votre-site-internet-les-obligations-respecter).

**Фактическая обработка данных.** Код не подключает рекламные/аналитические трекеры. Реальные операции с почтой, доступ к ней, сроки хранения, настройки провайдеров и основания международных передач не проверены доступом к аккаунтам. Privacy должна соответствовать им, а не только исходникам. См. [CNIL: информация для пользователей](https://www.cnil.fr/fr/informer-les-personnes). Не подтверждается автоматически действие Vercel DPA для неизвестного текущего тарифа.

**Коммерческое использование хостинга.** В ранее присланном экране импорта указан Hobby; текущий тариф через API не подтверждён. [Vercel Fair Use Guidelines](https://vercel.com/docs/limits/fair-use-guidelines) ограничивают Hobby личным некоммерческим использованием; продвижение платных услуг входит в примеры коммерческого использования. Если проект остаётся на Hobby, для коммерческого запуска требуется соответствующий тариф или другой подходящий хостинг. Оплата, тариф и настройки проекта не изменялись.

**Итоговый домен и почта.** `siteUrl` остаётся null: неподтверждённый домен не вписан в canonical/og:url. Привязанный Vercel-проект известен, но его API в текущем подключении отвечает 403. Публичная доступность окончательного домена и загрузка его ассетов не подтверждены этим review. Адрес почты проверен в разметке, не проверялась доставка письма и не запускалось почтовое приложение посетителя.
