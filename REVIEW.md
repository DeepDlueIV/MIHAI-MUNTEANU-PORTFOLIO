# Owner-oriented self-review

Дата: 16.10.2026. Это самостоятельное review с позиции владельца продукта, не независимое ревью и не утверждение, что реальный владелец уже одобрил сайт.

## Результат

Пять компактных секций, без фотографий, портретных заглушек, длинной биографии и фиктивных достижений. Около 200 слов основных описаний и ключевых текстов; навигация, подписи схем и демонстрационные данные считаются отдельно. Все три проекта явно обозначены как concept studies.

Графитовый первый экран, тёплые светлые секции, синий акцент, монограмма MM. Одна процедурная 3D-система и одна карусель. На desktop и mobile специализация и основное действие видны без чтения всей страницы.

## Ограничения и внешние данные

- Firefox, WebKit, физические телефоны и реальный профиль браузера заказчика не проверялись. Эмуляция ширин не выдаётся за тест на устройстве. Проверка CSS zoom — только дополнительная нагрузка на layout, не подтверждение реального browser zoom.
- Lighthouse и полевые Core Web Vitals не измерялись. Проверка типов без ошибок не отменяет стандартное предупреждение сборщика о размере отдельного, динамически загружаемого Three.js-чанка.
- Email и окончательный домен не предоставлены: `contactEmail` и `siteUrl` в `src/data/profile.ts` остаются `null`. Нет выдуманных контактов и canonical URL. Настройка SMTP/Resend не входит в задачу.
- На внешнем хостинге сайт не опубликован, DNS и настройки Vercel не изменялись. Код находится в `feat/portfolio`, PR №1, без объединения в `main`.
